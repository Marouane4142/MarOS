# MarOS 4.0.0-beta.1

**First public beta** of MarOS, a native Android TV home derived from [tv-home](https://github.com/mihirgupta0900/tv-home).

## Included

- A new MarOS identity, native vector controls and local Manrope typography.
- Favorite apps, collections, custom banners, three appearance presets and ambient landscapes.
- Compatible music controls and chronological, usable viewing entries.
- A paired local phone companion for photos, favorites, text and shortcuts. Sessions remain available across app changes for one hour.
- User-selected city weather, a local agenda/timer and optional connected-device integrations.
- MIT code license with upstream credits, contributing instructions, privacy documentation and journaled ADB installation/rollback tools.

## Download and install

Use the attached **MarOS-4.0.0-beta.1.apk** and verify it against **SHA256SUMS.txt**. Source archives are provided by GitHub from this tag. Read the [backup-first installation guide](https://github.com/Marouane4142/MarOS/blob/v4.0.0-beta.1/docs/INSTALLATION.md) before changing HOME or disabling a stock component.

- Minimum Android: **11 / API 30**. Current target SDK: **30**.
- Package: **io.github.marouane4142.maros**; versionCode: **40000**.
- The interface is currently primarily **French**.
- This is a **separate public package** with a new release signer. It does not overwrite or automatically migrate the earlier private `com.mihir.tvhome` app.

## Scope and limits

The predecessor was exercised on a Xiaomi TV Box S 2nd generation running Android 11. Broader device/remote compatibility is not established. Validation of this public package is documented in the repository and linked Actions runs; it is not a certification of every integration.

Media controls and recent viewing depend on metadata provided by each app. Universal Netflix/Prime/TiviMate history is not promised. Jellyfin, Home Assistant, Wake-on-LAN, cameras, casting, voice and an external assistant need their own compatible configuration and end-to-end testing.

Weather has no preset location. The companion uses **trusted-LAN HTTP**, not encrypted Internet hosting: do not forward port 8765. Installing this APK does not automatically clean manufacturer packages or enable special access. Debug CI artifacts are not official release APKs and use a different signer.

No private signing key, TV backup, personal settings or private source archive is included in this release.
